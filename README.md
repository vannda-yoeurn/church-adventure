# ដំណើរផ្សងព្រេងនៃពួកជំនុំ (Adventure of the Church)

ហ្គេម Adventure + RPG ជាភាសាខ្មែរ ដែលលេងបានលើ Browser ទាំងនៅលើកុំព្យូទ័រ និងទូរស័ព្ទ។
ហ្គេមនេះផ្អែកលើសៀវភៅ **«ប្រវត្តិសាស្ត្រក្រុមជំនុំ ៖ ការសិក្សាស្វែងយល់តាមយុគសម័យ»**
ដោយ គ្រូគង្វាល យឿន វ៉ាន់ដា (វិទ្យាស្ថានទេវសាស្ត្រថេអូខៃរ៉ុស)។

## មាតិកាក្នុងហ្គេម

- **៥ ភាគ ១៥ ជំពូក** តាមសៀវភៅ ចាប់ពីថ្ងៃបុណ្យទី៥០ (គ.ស. ៣០) រហូតដល់ពួកជំនុំខ្មែរសព្វថ្ងៃ
- **ផែនទីពិភពលោក** ដែលបើកជំពូកថ្មីម្តងមួយៗ និង **ផែនទីដើរលេង** ១៥ ផ្ទាំងផ្សេងគ្នា (វាលខ្សាច់ បណ្ណាល័យ ទីក្រុង យុគងងឹត ព្រៃឈើ វត្តអារាម សមុទ្រ សមរភូមិ ព្រៃត្រូពិច វាលស្រែខ្មែរ…)
- **បេសកកម្មក្នុងជំពូកនីមួយៗ**៖ ប្រមូលក្រាំង ៣ → និយាយជាមួយតួអង្គប្រវត្តិសាស្ត្រ → ដោះប្រស្នានៅលើផ្ទាំងថ្ម → បើកទ្វារ → ប្រយុទ្ធជាមួយមេស្រមោល
- **ការប្រយុទ្ធ**៖ ⚔️ ដាវនៃព្រះវិញ្ញាណ (ឆ្លើយសំណួរត្រូវ ដើម្បីវាយ) · 🛡️ ខែលនៃសេចក្តីជំនឿ · 🙏 អធិស្ឋាន
- **ជម្រើសរបស់អ្នកលេង** ធ្វើឲ្យ «ភាពស្មោះត្រង់ 🕯️» ឡើង ឬចុះ ហើយមាន **ចុងបញ្ចប់ ៣ បែប**
- **Level / XP / ពិន្ទុ / ផ្កាយ ៣** សម្រាប់ជំពូកនីមួយៗ
- **Save/Load**៖ រក្សាទុកស្វ័យប្រវត្តិ + ៣ កន្លែងរក្សាទុក + កូដសម្រាប់ផ្ទេរទៅឧបករណ៍ផ្សេង
- **ភ្លេង** (ស្ងប់ពេលដើរ · រំភើបពេលប្រយុទ្ធ · ជ័យជម្នះពេលឈ្នះ) និង **សំឡេងធម្មជាតិ** (សត្វស្លាប ខ្យល់ ទឹកហូរ រលក កង្កែប ចង្រិត ទីទុយ កណ្តឹង…) ត្រូវបានបង្កើតដោយកូដទាំងអស់ ដូច្នេះគ្មានបញ្ហាសិទ្ធិអ្នកនិពន្ធឡើយ
- **សំឡេងនិយាយជាភាសាខ្មែរ**៖ ប្រើឯកសារដែលលោកថតផ្ទាល់ ឬសំឡេងអាន km-KH របស់ឧបករណ៍ (មាននៅលើទូរស័ព្ទ Android មួយចំនួន)
- **លេងបានដោយគ្មានអ៊ីនធឺណិត** (ពុម្ពអក្សរ Kantumruy Pro និង Moul ត្រូវបានដាក់នៅក្នុងហ្គេមរួចហើយ)

## របៀបដាក់លើ GitHub Pages

1. ចូល github.com → **New repository** → ដាក់ឈ្មោះ ឧ. `church-adventure` → **Public** → **Create repository**
2. ចុច **uploading an existing file** → អូស **ឯកសារ និងថតទាំងអស់** ក្នុងថតនេះចូល (index.html, css, js, fonts, audio, …) → **Commit changes**
3. **Settings → Pages** → Branch៖ `main` និង `/ (root)` → **Save**
4. រង់ចាំ ១–២ នាទី ហើយហ្គេមនឹងបើកបាននៅ `https://ឈ្មោះលោក.github.io/church-adventure/`

> លេងនៅលើកុំព្យូទ័រផ្ទាល់៖ បើក `index.html` ក្នុង Chrome ក៏បានដែរ។ ប៉ុន្តែឯកសារសំឡេងថត ដំណើរការតែនៅពេលហ្គេមនៅលើ GitHub Pages ឬ web server ប៉ុណ្ណោះ។

## របៀបកែរឿង ឬបន្ថែមសំណួរ

រឿងទាំងអស់ស្ថិតនៅក្នុង `js/data.js` តែមួយ។ លោកអាចបើកវាដោយ Notepad ឬ VS Code ហើយកែអត្ថបទខ្មែរដោយផ្ទាល់៖

- `["peter", "អត្ថបទ…"]` = ប្រយោគមួយ (`narr` = អ្នកនិទាន · `teacher` = លោកគ្រូ វ៉ាន់ដា · `{name}` = ឈ្មោះអ្នកលេង)
- `questions` = សំណួរប្រយុទ្ធ — **ចម្លើយទីមួយ គឺជាចម្លើយត្រូវជានិច្ច** (ហ្គេមនឹងលាយលំដាប់ដោយខ្លួនឯង)
- `puzzle` ប្រភេទ `order` = ដាក់ព្រឹត្តិការណ៍តាមលំដាប់ត្រឹមត្រូវ · ប្រភេទ `match` = ផ្គូផ្គង [ពាក្យ, អត្ថន័យ]
- `choice.options[].faith` = ពិន្ទុភាពស្មោះត្រង់ (+២ / −១)

## របៀបដាក់សំឡេងនិយាយជាភាសាខ្មែរ

1. បើក `voice-script.csv` ក្នុង Excel ឬ Google Sheets។ ប្រយោគនីមួយៗមាន `id`។
2. ថតប្រយោគនីមួយៗជា MP3 ហើយដាក់ឈ្មោះតាម id (ឧ. `c01_peter_01.mp3`)។ នៅពេលថត កន្លែងដែលមានឈ្មោះអ្នកលេង សូមនិយាយថា «មិត្តអើយ»។
3. ដាក់ឯកសារទាំងនោះក្នុង `audio/voice/`
4. សរសេរ id ទាំងនោះក្នុង `audio/voice/manifest.json` ឧ. `["p_00","p_01","c01_peter_00"]`
   (ឬរត់ `node tools/make-voice-script.js --manifest` ដើម្បីធ្វើដោយស្វ័យប្រវត្តិ)

មិនចាំបាច់ថតទាំងអស់ក្នុងពេលតែមួយទេ។ ប្រយោគណាដែលគ្មានឯកសារ ហ្គេមនឹងប្រើសំឡេងអានរបស់ឧបករណ៍ (បើមាន) ឬបង្ហាញតែអត្ថបទ។
